# Centro Culturale L'Innominato - GitHub Pages

Questa cartella è pronta per essere caricata in un repository GitHub e pubblicata con GitHub Pages.

## Come pubblicare

1. Crea o apri il repository su GitHub.
2. Carica **tutti** i file di questa cartella nella root del repository.
3. Vai su **Settings > Pages**.
4. In **Build and deployment**, scegli **Deploy from a branch**.
5. Seleziona il branch `main` e la cartella `/ (root)`.
6. Salva.

## Note

- Il sito usa percorsi relativi, quindi funziona sia su dominio personalizzato sia su URL GitHub Pages del tipo `https://centroculturalelinnominato.github.io/NOME-REPO/`.
- È stato corretto il riferimento all'immagine `hero-4.jpeg`.
- Sono state aggiunte le pagine `privacy.html` e `cookie.html` come segnaposto tecnico.
- I form sono stati convertiti in invio `mailto:` per evitare errori su hosting statico.
- Il file `.nojekyll` evita interferenze di Jekyll con GitHub Pages.
